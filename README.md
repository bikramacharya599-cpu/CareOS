# CareOS v0.1

Initial private-use web application foundation for a home-care agency operations platform.

## Included in this foundation
- Orange CareOS command-center dashboard
- Employees
- Clients
- Scheduling / open shifts
- Private-use EVV-style visits
- Incident records
- MUI records
- Audit center
- Integration roadmap for Sandata, Xoomia/DODD and ADP

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Important
This is an application foundation, not a production HIPAA environment or Medicaid-certified EVV system. Production use with protected health information requires appropriate security, access controls, audit logging, encryption, backups, vendor agreements and compliance review.
